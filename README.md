# ApexSDK-transitional

This is a **TRANSITIONAL PLUGIN** to be used as a stub for **UE4-APEX-SDK** to help transition a project to the
newer `pixo-unreal-auth`, `pixo-unreal-datareporting` and `pixo-unreal-multiplayer` framework.

This plugin basically creates the data types needed to allow a project to successfully open in the editor,
but this plugin will not work for any other purpose than allowing you to convert your blueprints to the
newer framework.

This should not be used for production!  It should be deleted after your project is converted to the new
framework.
