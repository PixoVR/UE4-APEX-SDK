\mainpage About the SDK

This is an Unreal Engine plugin which implements the %Apex API, supporting
Unreal Engine **4.26.0** to **4.27.2**.

Communication to the %Apex Server uses REST https JSON requests which follow the xAPI Standard.

Useful links:

 - Github Repo: $(PROJECT_REPO)
 - Demo: $(PROJECT_DEMO)
 - %Apex Server: $(APEX_SERVER_URL)
 - %Apex Module Server: $(APEX_MODULESERVER_URL)
 - xAPI Spec: $(XAPI_REPO_URL) (currently using v1.03)
